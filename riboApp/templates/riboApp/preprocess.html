Pre-Processing

What is Preprocessing?

Preprocessing converts raw ribosome profiling FASTQ files into analysis-ready parquet format through a standardized pipeline:

Quality Control: Remove low-quality reads and adapter sequences
Length Filtering: Select ribosome footprint reads (typically 28-32 nucleotides)
Genome Alignment: Map reads to reference genome and annotate genomic regions
Data Export: Generate parquet files optimized for fast analysis

How to Run Everything

1

Prepare Sample Lists

Create text files listing your samples and FASTQ file paths (see format below)

2

Generate Scripts

Use this form to generate riboflow processing scripts with your parameters

3

Run Processing

Execute the generated bash script on your compute cluster or local machine

4

Upload Results

Upload the resulting parquet files to RiboApp for analysis

Input File Format

Provide sample lists in text files with one sample per line:

Ribosome Profiling Samples (Required):
sample1_ribo /path/to/ribo1.fastq.gz
sample2_ribo /path/to/ribo2.fastq.gz
sample3_ribo /path/to/ribo3.fastq.gz
mRNA-seq Samples (Optional):
sample1_mRNA /path/to/mrna1.fastq.gz
sample2_mRNA /path/to/mrna2.fastq.gz
sample3_mRNA /path/to/mrna3.fastq.gz
Tips:
  • Use descriptive sample names (e.g., "P42_Kidney_Ribo_rep1")
  • Ensure file paths are accessible from your compute environment
  • Both space-separated and CSV formats are supported
  • mRNA-seq data is optional but recommended for comparative analysis
