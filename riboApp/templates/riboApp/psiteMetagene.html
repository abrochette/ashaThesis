P-site Offset Metagene Analysis

About This Analysis:

This analysis generates metagene plots showing ribosome coverage around start and stop codons after applying P-site offsets. The plots are similar to those generated by the ribor R package but work directly with your parquet files.

  • Start Codon Plot: Shows ribosome occupancy from -30 to +62 nucleotides relative to start codons
  • Stop Codon Plot: Shows ribosome occupancy from -2 to +60 nucleotides relative to stop codons
  • P-site Correction: Applies read length-specific P-site offsets from your offset CSV file
  • Normalization: Read counts are normalized to reads per million (RPM) for comparison
